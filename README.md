Entry for the make.fun bounty [Sum up 26 November's world news in one image](https://make.fun/bounty/news-image-20261126).

One 1024×1024 newspaper front page: 40 stories, 9 regions, Thursday 26 November 2026 —
masthead, stat strip, 3 drawn lead panels, the UTC Ribbon timeline, 12 numbered cards,
world map with pins, ALSO list, and a DATE CHECK footer. Every story happened or was first
reported on Thursday 26 November 2026; sources named on each story.

Built with AI agents (Hermes / Nemotron-3-Ultra). The entrypoint `main.ts` copies the
generated image to the output directory; the page itself is drawn by `tools/generate.py`.
